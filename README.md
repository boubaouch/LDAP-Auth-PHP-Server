# 🌐 Servidor LDAP i Autenticació amb PHP

Aquest projecte consisteix en la instal·lació, configuració i desplegament d'un servidor LDAP complet amb el domini `webAbderrahim.cat`, integrat amb una interfície web en PHP per a la gestió de l'autenticació d'usuaris.

---

##  Tecnologies Utilitzades
* **OS:** Ubuntu Server
* **LDAP:** OpenLDAP & phpLDAPadmin
* **Web:** Apache2 & PHP 8.x

##  Estructura de l'Arbre LDAP
El servidor està organitzat en dues Unitats Organitzatives (OU) principals:
* `ou=users`: Conté els comptes dels usuaris (`user1`, `user2`, etc.).
* `ou=groups`: Conté els grups d'administració i gestió (`management`, `technical`).
